سامسونگ تایزن · تلویزیون‌های ۲۰۲۱ و جدیدتر

آب‌وهوای کپنهاگ، ساخته‌شده برای تلویزیون.

تمام‌صفحه در ۱۹۲۰×۱۰۸۰، کنترل با ریموت، و اجرا روی موتور مرورگری که از سال ۲۰۲۱ دیگر به‌روز نشده است. یک فایل .wgt امضاشده که مستقیم روی تلویزیون نصب می‌شود.

روی تلویزیون خودتان نصب کنید کد منبع

روزهای آینده

مستقیم از Open-Meteo. بدون کلید، بدون واسط، همان درخواستی که تلویزیون می‌فرستد.

    با کلیدهای جهت‌دار کنترلش کنید

    این خودِ اپلیکیشن است، نه فیلم. همان فایل‌هایی که داخل بسته‌ی .wgt قرار می‌گیرند. کلیدهای جهت‌دار جابه‌جا می‌کنند و Enter انتخاب می‌کند. چهار دکمه‌ی زیر همان کلیدهای رنگی ریموت هستند.

    اول روی قاب کلیک کنید تا کلیدها را بگیرد. روی گوشی، اپلیکیشن در اندازه‌ی تلویزیون نشان داده می‌شود، پس متن کوچک می‌ماند. و همین نکته‌ی ماجراست.

    چرا این شکلی است

    سه محدودیت، هر تصمیمی را در این اپلیکیشن شکل داده است.

    • موتور مرورگر ثابت مانده

      کرومیوم تلویزیون به فریمور آن گره خورده و هرگز به‌روز نمی‌شود. تلویزیون ۲۰۲۱ روی کرومیوم ۷۶ مانده است. یعنی flex gap، clamp() و ?. کنار می‌روند، و یک لینتر در هر بیلد همه‌ی فایل‌ها را با همین سقف می‌سنجد.

    • بدون کلید، بدون سرور

      Open-Meteo کلید API نمی‌خواهد و درخواست از دامنه‌ی دیگر را می‌پذیرد، پس اپلیکیشن خودش داده را می‌گیرد. آخرین پاسخ سالم ذخیره می‌شود و شروع بدون شبکه هم پیش‌بینی را نشان می‌دهد.

    • عیب‌یابی در تاریکی

      تلویزیون خانگی DevTools ندارد و sdb shell خروجی نمی‌دهد. پس اپلیکیشن ابزار خودش را همراه دارد: یک مهر بیلد در گوشه‌ی صفحه و یک لایه‌ی عیب‌یابی روی کلید آبی.

    روی تلویزیون خودتان نصب کنید

    به ابزارهای خط فرمان Tizen Studio نیاز دارید، اما خودِ IDE لازم نیست. حدود ده دقیقه، که بیشترش انتظار برای راه‌اندازی مجدد تلویزیون است.

    1. حالت توسعه‌دهنده را روشن کنید

      در تلویزیون بخش Apps را باز کنید، ۱۲۳۴۵ را بزنید، Developer mode را روشن کنید، نشانی IP این کامپیوتر را وارد کنید و تلویزیون را دوباره راه‌اندازی کنید.

    2. یک پروفایل امضا بسازید

      فایل .wgt باید امضا شود. یک گواهی خودامضا برای نصب روی بیشتر تلویزیون‌ها کافی است.

      tizen certificate -a me -p PASSWORD -f me -- certs
tizen security-profiles add -n MyTV -a certs/me.p12 -p PASSWORD

    3. بسته‌بندی و نصب

      یک فرمان، لینت و بسته‌بندی و نصب و اجرا را انجام می‌دهد. نشانی IP تلویزیون خودتان را بگذارید.

      git clone https://github.com/cocodedk/copenhagen-weather-tv
cd copenhagen-weather-tv
TIZEN_PROFILE=MyTV ./build.sh --install 192.168.0.201
